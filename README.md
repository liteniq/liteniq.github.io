# RIMONY public support and ad verification

This public repository contains only the support page and AdMob authorized-seller file.
The Android application source is maintained separately in a private repository.

- Support: https://liteniq.github.io/

- Existing privacy policy: https://liteniq.github.io/rimony-privacy/
- Publish: GitHub Pages, main branch, repository root

Keep the publisher ID in app-ads.txt identical to the snippet shown in the RIMONY AdMob account.
